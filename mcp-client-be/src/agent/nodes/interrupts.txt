**Add a checkpointer to your graph compilation and call `interrupt()` directly inside your file rename or copy tool definition.**

To pause execution for human-in-the-loop approval before executing sensitive operations like file manipulation, use the `interrupt` function from `@langchain/langgraph`. When the tool calls `interrupt()`, LangGraph pauses execution, saves state via the checkpointer, and waits for a `new Command({ resume: ... })` input.

```typescript
import { StateGraph, START, END, MemorySaver, Command, interrupt } from "@langchain/langgraph";
import { tool } from "@langchain/core/tools";
import * as z from "zod";

// Define a file copy/rename tool that interrupts for user confirmation
const copyOrRenameFile = tool(
  async ({ source, destination, action }) => {
    // Pause execution and request confirmation
    const response = interrupt({
      action,
      source,
      destination,
      message: `Do you want to ${action} ${source} to ${destination}?`,
    }) as { approved: boolean };

    if (!response.approved) {
      return `Action ${action} cancelled by user.`;
    }

    // Perform file operation here once approved
    return `Successfully performed ${action}: ${source} -> ${destination}`;
  },
  {
    name: "copy_or_rename_file",
    description: "Copy or rename files with human approval.",
    schema: z.object({
      source: z.string().describe("Source file path"),
      destination: z.string().describe("Destination file path"),
      action: z.enum(["copy", "rename"]).describe("The file action to perform"),
    }),
  }
);

// Compile graph with a checkpointer (required for interrupts)
function createGraph() {
  return new StateGraph(AgentState)
    .addNode("llm", llmNode)
    .addNode("tools", toolNode)
    .addEdge(START, "llm")
    .addConditionalEdges("llm", toolsCondition, {
      tools: "tools",
      [END]: END,
    })
    .addEdge("tools", "llm")
    .compile({
      checkpointer: new MemorySaver(), // [!code highlight]
    });
}
```

When the tool runs and triggers `interrupt()`, catch the interrupt response in your invocation loop and resume by passing a `Command`:

```typescript
const config = { configurable: { thread_id: "thread-1" } };

// Initial invoke - pauses when tool calls interrupt()
let result = await graph.invoke({ messages: [...] }, config);

// Resume execution after user approves
let finalResult = await graph.invoke(
  new Command({ resume: { approved: true } }),
  config
);
```
